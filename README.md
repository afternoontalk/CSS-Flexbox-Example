# CSS-Flexbox-Example

**Overview
This project demonstrates CSS Flexbox through an interactive “Mood Planet” web app. Users select options for Character, Weather, Style, and Mood, and the layout dynamically adjusts using Flexbox properties. The project highlights how Flexbox can manage alignment, spacing, and responsiveness in web design.

**Pages
1.	Cover Page (cover.html)
  Intro to the interactive game
  Anchor link button to go to the selection page
2.	Selection Page (index.html)
  Users choose options for their “Mood Planet”
  Flexbox used to layout option groups and center content
  Clicking Generate Planet could later lead to a result page

##Key Flexbox Concepts Used
•	display: flex – create flexible containers
•	flex-direction – row or column alignment
•	justify-content – horizontal alignment of items
•	align-items – vertical alignment of items
•	gap – spacing between flex items
These properties are applied to option groups, buttons, and the main container to make the UI neat and responsive.

**Instructions
1.	Open cover.html in a web browser.
2.	Click “Start Your Planet” to go to the selection page (index.html).
3.	Choose one option from each category (Character, Weather, Style, Mood).
4.	Observe how the layout and selections are visually aligned using Flexbox.
